📖 About
Porsche is a case study project demonstrating modern web development practices. It showcases a sophisticated, responsive design inspired by luxury automotive branding, built with contemporary web technologies to deliver an exceptional user experience.

🚀 Getting Started

### Prerequisites
```
node >= 18.x
npm or yarn
```

### Installation
```bash
# 1. Clone the repo
git clone https://github.com/sohamchavan07/Porsche.git
cd Porsche

# 2. Install dependencies
npm install
# or
yarn install

# 3. Start the development server
npm run dev
# or
yarn dev
```

Open http://localhost:3000 in your browser.

---

💡 Usage
```bash
# Build for production
npm run build

# Run in production mode
npm run preview
```
